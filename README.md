# FleetERP - Manufacturing ERP Data Analytics System

## Overview
A simulated ERP data analytics project designed to analyze manufacturing operations, including:

- Inventory management
- Bill of Materials (BOM)
- Work orders
- Production performance
- Data quality validation

## Technologies
- SQL (PostgreSQL)
- Python (Pandas)
- Excel / Power BI

## Key Features
- Designed relational ERP database structure
- Cleaned and transformed operational data
- Created SQL queries for business analysis
- Identified inventory issues and data inconsistencies

## Business Questions
- Which parts have inventory shortages?
- Which work orders are delayed?
- What are the production trends?
